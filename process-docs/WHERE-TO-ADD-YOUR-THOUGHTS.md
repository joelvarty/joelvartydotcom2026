## Writing Tips

Your voice in these docs is:
- **Conversational** - Write like you're explaining to a friend
- **Direct** - No fluff, get to the point
- **Story-driven** - "Here's what I was thinking..." not "One might consider..."
- **Practical** - Focus on real motivations, not abstract ideals

### Good Examples from Existing Docs

From switching-to-claude-code.md:
> "But here's the thing about AI development tools - they're evolving rapidly,
> and it's worth experimenting. I've been hearing great things about Claude Code,
> Anthropic's official CLI tool, and I wanted to see how it handles project
> handoff and continuation."

From planning:
> "I want to avoid a monolithic approach where we commit to one big framework too
> early. Start with the foundation, then layer in features as they're needed."

### What NOT to Write

Avoid:
- ❌ "This feature provides excellent functionality for..."
- ❌ "The implementation demonstrates best practices..."
- ❌ "One might consider this approach beneficial because..."

Instead:
- ✅ "I wanted this because..."
- ✅ "The old way was annoying me because..."
- ✅ "Here's what I was thinking..."
